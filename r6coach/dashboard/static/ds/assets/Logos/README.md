# Logos

The mark is four voice bars: the coach speaking. It is an original mark; it does not use, echo or sit beside Ubisoft's Rainbow Six logo.

- `rc-lockup.svg` — Mark in `signal` amber plus "R6 COACH" in `ink` (#e8eaee), outlined from Hubot Sans Bold at width 85. The primary logo on dark grounds.
- `rc-lockup-ink.svg` — Mark in `signal-ink` (#8a5200) plus the wordmark in `ink` (#14171c). The logo on light grounds.
- `rc-mark.svg` — The mark alone in `signal` amber (#f2a93b). Dark grounds.
- `rc-mark-ink.svg` — The mark alone in `ink` (#14171c). Light grounds, where amber falls below 3:1.
- `rc-app-icon.svg` — Amber tile with `on-signal` bars. Tray icon, taskbar icon and favicon, 16px and up; never on an amber ground.

Colours are baked in (single ink per part). Never stretch, outline, add glow, or put the mark inside a crosshair or reticle.
