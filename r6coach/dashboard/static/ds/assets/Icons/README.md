# Icons

24px grid, 1.75px rounded strokes. Line in mid grey (#868d97, 3:1 or better on `surface` in both themes) with one accent in `signal` amber (#f2a93b). Both colours are baked in; when inlining in the app, replace #868d97 with `currentColor` and #f2a93b with `var(--signal)`.

- `phase-map-ban.svg` — Map ban phase: folded map, amber slash.
- `phase-operator-ban.svg` — Operator ban phase: operator silhouette, amber ban sign.
- `phase-operator-select.svg` — Operator select phase: silhouette, amber check.
- `phase-prep.svg` — Prep phase: wall with amber reinforcement struts.
- `phase-action.svg` — Action phase: stopwatch, amber hand.
- `phase-recap.svg` — Between rounds: speech bubble with amber voice bars.
- `coach.svg` — The coach / audio output: headset with voice bars.
- `push-to-talk.svg` — Push-to-talk key: keycap with amber mic.
- `screen-read.svg` — "What the coach sees": monitor with amber capture brackets.
- `drone-route.svg` — Drone path advice: dotted route, amber arrow.
- `objective.svg` — Bomb site / plant spot: diamond, amber core.
- `round-win.svg` — Round or match won: trophy, amber check.
