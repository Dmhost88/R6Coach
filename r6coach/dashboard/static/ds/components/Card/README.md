# Card

The one container: a `surface` panel with a `line` border, `radius-lg` corners and `space-4` padding.

- Markup: `<section class="rc-card">`, an optional `<h2 class="rc-card__title">` in `label` style, then any content; `rc-card__hint` for the closing helper line.
- Titles are sentence case and short: "Match", "Coach", "Operator pool".
- Cards don't nest and don't take shadows or coloured edges. Separate cards with a `space-4` gap.
